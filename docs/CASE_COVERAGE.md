# Соответствие PDF кейса

Источник — исходный PDF, 19 страниц. DOCX использован как вспомогательный план, а не как доказательство статистики или качества.

| Условие | Реализация / проверка | Остаток |
|---|---|---|
| Контекст компании, с.6 | Потоковый импорт полного CSV; отрасль, масштаб, регион, продукты, ФТС, группа, наблюдаемые связи | Доля рынка неизвестна без объёма рынка; единицы выручки требуют подтверждения |
| Парсер и классификация, с.6 | Официальный RSS ЦБ, импорт официального HTTPS, извлечение PDF/OCR, темы и дедупликация | Подключение дополнительных RSS — расширение; сейчас автосбор ЦБ |
| Персональное ранжирование | Правила по признакам компании и роли; изменение баллов проверено тестами | Экспертная калибровка релевантности |
| Глубокая интерпретация | Схема: объяснение, риски, возможности, действия, ограничения, уточнения | **Живая LLM не проверена без реквизитов шлюза** |
| Экспертиза банка | Корпус из 9 PDF / 64 страниц; FTS, дословные фрагменты, дата/страница и ссылка на PDF | У одного обзора нет точного дня: исключён из текущего поиска; OCR требует контроля |
| Агентность, с.7 | Собственный контроллер, выбор инструментов моделью, единый контекст, повторный поиск, валидация и до двух исправлений | Контроллер проверен тестовым шлюзом; необходим живой прогон |
| Интерфейс Альфа-Бизнеса | Русский макет главной с постоянной точкой входа; лента, карточка, вопросы, роль, источники | Это самостоятельный конкурсный макет, не банковская интеграция |
| Новые события | Импорт ранее неизвестного текста/официальной URL; одинаковый механизм для новых компаний | Качество LLM на отложенных событиях ещё не измерено |
| Работа с шумными данными | Исходные варианты сохраняются; конфликтующие поля не выбираются; неизвестные контрагенты остаются неизвестными | Семантика спорных полей требует организаторов |
| Безопасность, с.12 | Ограниченные инструменты/URL, бюджет, код доступа, серверные ключи, журнал, разделение контекстов | Для банка нужен настоящий IAM; общий код лишь для стенда |
| Разрешённые LLM, с.18 | Конфигурация только одной из 6 семей, никаких внешних агентов/embedding-LLM | Организаторы должны дать точный ID, endpoint, ключ, тарифы |
| Мониторинг и метрики | Задержки, режимы, обратная связь, usage ledger и план экспертной оценки | Нет оснований объявлять Precision@5 и бизнес-эффект достигнутыми |
| Масштабируемость | Потоковая загрузка 1,38 млн строк, индексы, кэш, отдельные слои данных/поиска/агента | Нагрузочная оценка конкретного VPS и многопроцессная архитектура — отдельно |
| Материалы сдачи, с.8 | Код, README, Docker, lock-файлы с хешами, notices, синтетический сценарий, API и тесты | Фиксация версии до неизвестного дедлайна, доступ жюри и хостинг — владельцем |

Полное соответствие условиям не объявляется до живого прогона разрешённой модели, экспертной проверки и определения доступного жюри способа подключения. Подготовленный режим по правилам не подменяет AI-часть.
