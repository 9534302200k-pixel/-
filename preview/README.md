# Визуальная демонстрация без установки

Онлайн: https://9534302200k-pixel.github.io/-/ — открывается в Chrome/Edge без регистрации, Docker и установки программ.

`business-pulse.html` — один самостоятельный HTML-файл. Скачайте его и откройте двойным щелчком в Chrome или Edge. Не требует Docker, Python, сервера, административных прав или подключения к модели.

Можно переключать четыре учебные компании и три роли, открывать карточки событий и источники, просматривать журнал, сохранять события и использовать сценарный калькулятор. Состояние сбрасывается при перезагрузке страницы. Все данные синтетические. Примеры аналитики подготовлены заранее контроллером в режиме правил; это явно обозначенная визуальная демонстрация, а не живой AI-анализ. Импорт и загрузка новостей требуют основной серверной версии.

Обновление демо из исходников:

```bash
.venv/bin/python -m scripts.export_visual_demo
cd frontend
npm exec -- tsc -b
npm exec -- vite build --config vite.visual.config.ts
cd ..
.venv/bin/python -m scripts.package_visual_demo
```

Экспорт всегда создаёт отдельную временную БД с синтетическими фикстурами и не читает исходный корпус кейса. Основная production-сборка не включает режим демонстрации.
