# Проверено в этой среде

20 октября 2026 года. Проверки относятся к текущей реализации и облачной машине; публичный VPS и шлюз LLM не использовались.

- `pytest -q`: 29 passed, включая 3 сценария в настоящем Chromium. Проверены серверный API, импорт, ограничения, контроллер модели с тестовым шлюзом, десктопный сценарий, новая тестовая новость и мобильная навигация.
- `npm run build`: TypeScript и production-сборка React прошли.
- `bash scripts/setup_cloud.sh`: повторная установка по lock-файлам с SHA-256, сборка frontend и локальная настройка русского OCR прошли.
- Docker image собран с TLS-проверкой, Debian signatures и `pip --require-hashes`. Для облачного прокси использован `scripts.build_cloud`; доверенный CA bundle монтируется временно, проверки не отключались.
- Финальный Compose запущен отдельным проверочным проектом: контейнер healthy, функциональный `scripts.smoke` прошёл. После перезапуска сохранены БД, анализы и закладка. Это проверка запуска контейнера, а не живая LLM.
- Полный кейс скачан по двум исходным ссылкам. Импортировано 85 525 строк профилей / 85 514 компаний, 1 380 585 строк платежей, 12 514 строк связей. Повторный импорт всех трёх CSV: 0 новых записей.
- 9 банковских PDF / 64 страницы распознаны OCR `rus+eng`. Проверена также отдельная растровая страница с русским текстом. 8 документов получили даты, подтверждённые текстом исходных страниц; один обзор золота без точного дня остаётся вне текущего поиска.
- Две RSS-ленты Банка России: 62 материала. Реальные профили получают реальные события и банковские фрагменты; подготовленные учебные события в их ленте исключены.
- В браузере открыты профиль из реального CSV, реальная новость, анализ по правилам и цитаты банковских PDF. В проверенных сценариях ошибок JavaScript нет; при ширине 390 px горизонтальное переполнение отсутствует.

Осталось до полной конкурсной проверки: получить endpoint/ключ/model ID/тарифы организаторов, проверить живое планирование и генерацию на разрешённой модели, оценить содержательное качество на отложенных событиях, подтвердить единицы финансовых полей и доступ жюри.
